# Dashboard de Vendas

## Objetivo

Projeto desenvolvido para prática de análise de vendas e construção de dashboards em Power BI.

## Ferramentas Utilizadas

- Power BI
- Excel

## Indicadores Analisados

- Faturamento
- Volume de vendas
- Produtos mais vendidos
- Desempenho comercial

## Resultado

O dashboard foi desenvolvido para consolidar informações comerciais e apoiar análises relacionadas ao desempenho de vendas.

## Aprendizados

Durante este projeto pratiquei conceitos de análise de dados, criação de indicadores de negócio e construção de dashboards para suporte à tomada de decisão.
